# Rust Windows 11 CPU/Memory Overlay - V1 Spec

## 1. Overview

Build a very small, lightweight native Windows 11 desktop app in **Rust** that displays:

* `CPU xx%`
* `MEM xx%`

The app should appear as a tiny overlay window near the Windows taskbar area and refresh once per second.

This first version should be kept as minimal as possible.

---

## 2. Goal

Create a minimal working app that:

* continuously shows current CPU usage percentage
* continuously shows current memory usage percentage
* refreshes every second
* stays visible on screen near the taskbar
* uses very little system resources

---

## 3. Non-Goals

This version does **not** need:

* settings UI
* right-click menu
* reposition controls
* refresh rate options
* text scaling options
* startup with Windows
* notification area / tray icon
* transparency options
* drag and drop support
* multiple monitor support
* charts or graphs
* advanced styling

---

## 4. Target Platform

* **OS**: Windows 11
* **Architecture**: x64
* **Language**: Rust
* **App Type**: Native desktop utility

---

## 5. Functional Requirements

## 5.1 Metrics Display

The app must display two lines of text:

```text
CPU xx%
MEM xx%
```

### Requirements

* `CPU xx%` shows current CPU usage percentage
* `MEM xx%` shows current memory usage percentage
* values should be shown as integers
* display should update once every second

---

## 5.2 Overlay Window

The app must show the metrics in a tiny always-visible overlay window.

### Requirements

* borderless window
* no title bar
* always on top
* small size
* visible near the taskbar area
* not intended for normal app interaction

---

## 5.3 Refresh Behavior

The app must refresh displayed values automatically.

### Requirements

* update interval: **1 second**
* UI text should update after each refresh
* app should continue running until manually closed

---

## 5.4 Position

The app should appear in a fixed default position near the taskbar area.

### Requirements

* initial version uses one hardcoded default position
* no user adjustment needed in v1

---

## 6. UI Requirements

### Display Format

The app should display exactly:

```text
CPU xx%
MEM xx%
```

### Visual Style

* simple text only
* minimal UI
* readable at small size
* no extra controls

---

## 7. Performance Requirements

The app should remain lightweight.

### Requirements

* low CPU overhead
* low memory usage
* refreshing once per second should not noticeably impact system performance

---

## 8. Error Handling

If the app cannot read the metrics, it should fail safely.

### Requirements

* show fallback text if needed, for example:

```text
CPU --
MEM --
```

* temporary metric read failures should not crash the app

---

## 9. Acceptance Criteria

The v1 app is acceptable when:

1. it runs on Windows 11
2. it displays `CPU xx%`
3. it displays `MEM xx%`
4. it refreshes once every second
5. it appears as a small always-on-top overlay near the taskbar
6. it stays lightweight
7. it does not require any settings or extra controls

---

## 10. Example Runtime Display

```text
CPU 18%
MEM 63%
```

---

## 11. Proposed v1 Scope

The first version includes only:

* Rust native app
* tiny borderless always-on-top overlay window
* CPU usage display
* memory usage display
* 1-second auto refresh
* fixed default position

---

## 12. Implementation Summary

This version should be built with the smallest possible scope:

* create a small overlay window
* read CPU and memory usage
* update text every second
* keep the app running and visible
